# Neo4j 知识图谱数据导入工具

## 概述

这个工具用于将Excel格式的知识图谱数据导入到Neo4j数据库中，支持三元组数据和实体属性数据的整合导入。

## 文件说明

- `load_complete_knowledge_graph.py` - 完整的知识图谱数据导入脚本
- `test_load.py` - 测试脚本，用于验证数据导入功能
- `load_node.py` - 原有的节点导入脚本（仅处理三元组）
- `load_labels.py` - 原有的标签更新脚本（仅处理实体类型）

## 数据格式要求

### 三元组数据文件（最终_纯三元组.xlsx）
- 列名：`首实体`, `关系`, `尾实体`
- 示例：
  ```
  首实体    关系      尾实体
  刀盘结泥饼  原因因素   黏土地层
  刀盘结泥饼  原因因素   含水率高
  ```

### 实体属性数据文件（最终_类型描述.xlsx）
- 列名：`实体名称`, `实体类型`, `属性`, `属性描述`
- 示例：
  ```
  实体名称   实体类型   属性   属性描述
  刀盘结泥饼  风险名称   描述   盾构机刀盘及刀具表面黏附大量黏土形成硬质泥块的现象...
  黏土地层   地质原因   描述   高黏性土层（如膨润土、高岭土）易吸附在金属表面...
  ```

## 使用方法

### 1. 环境准备

确保已安装必要的Python包：
```bash
pip install pandas py2neo openpyxl
```

确保Neo4j数据库正在运行，并且连接参数正确。

### 2. 配置数据库连接

在 `load_complete_knowledge_graph.py` 中修改数据库连接参数：
```python
loader = Neo4jKnowledgeGraphLoader(
    uri='bolt://localhost:7687',
    username="neo4j", 
    password="your_password"
)
```

### 3. 运行完整导入

```bash
python load_complete_knowledge_graph.py
```

程序会询问是否清空现有数据库，然后依次导入：
1. 三元组数据（创建节点和关系）
2. 实体属性数据（添加节点标签和属性）
3. 创建索引（提高查询性能）

### 4. 运行测试

```bash
python test_load.py
```

测试脚本会验证：
- 数据库连接
- 数据导入功能
- 数据完整性
- 示例查询

## 示例查询

### 查询所有风险名称节点
```cypher
MATCH (n:风险名称) RETURN n.name, n.描述
```

### 查询特定实体的所有关系
```cypher
MATCH (n {name: "刀盘结泥饼"})-[r]-(m) 
RETURN n.name, type(r), m.name
```

### 查询因果关系链
```cypher
MATCH (risk:风险名称)-[:原因因素]->(cause) 
RETURN risk.name, cause.name, labels(cause)
```

## 注意事项

1. **数据库备份**：导入前建议备份现有数据
2. **文件路径**：确保Excel文件路径正确
3. **内存使用**：大量数据导入时注意内存使用情况
4. **网络连接**：确保Neo4j数据库网络连接稳定
5. **权限设置**：确保数据库用户有足够的读写权限

## 故障排除

### 常见问题

1. **连接失败**
   - 检查Neo4j服务是否启动
   - 验证连接参数（URI、用户名、密码）
   - 检查网络连接

2. **文件读取错误**
   - 确认文件路径正确
   - 检查文件格式和编码
   - 验证列名是否匹配

3. **内存不足**
   - 减小批处理大小
   - 增加系统内存
   - 分批导入数据

4. **导入速度慢**
   - 检查网络延迟
   - 调整批处理大小
   - 确保数据库性能配置合理
