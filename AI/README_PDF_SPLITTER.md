## 工具文件

我为您创建了以下工具：

### 1. `pdf_splitter.py` - 核心分割工具
- **功能**: 将PDF文件分割成指定页数的多个小文件
- **使用方法**: 
  ```bash
  python pdf_splitter.py <PDF文件路径> [输出目录] [每个文件页数]
  ```
- **示例**:
  ```bash
  python pdf_splitter.py "big/【CRCC】盾构机操作手培训教材.pdf" "big_output" 50
  python pdf_splitter.py "big/盾构施工标准化手册.pdf" "big_output/附件：2" 30
  ```

### 2. `interactive_pdf_splitter.py` - 交互式工具
- **功能**: 提供友好的交互界面，自动搜索PDF文件并引导用户完成分割
- **使用方法**: 
  ```bash
  python interactive_pdf_splitter.py
  ```
- **特点**:
  - 自动搜索当前目录及子目录中的所有PDF文件
  - 显示文件信息（页数、大小）
  - 交互式设置分割参数
  - 友好的用户界面

### 3. `split_pdfs.bat` - 批处理脚本
- **功能**: 一键分割 `big` 目录中的PDF文件
- **使用方法**: 双击运行或在命令行中执行
- **特点**:
  - 自动检查和安装依赖
  - 预设分割参数
  - 适合重复操作

## 安装依赖

在使用工具前，请确保安装了必要的Python库：

```bash
pip install PyPDF2
```

## 使用步骤

### 方法一：使用交互式工具（推荐）
1. 打开命令行，进入工具所在目录
2. 运行：`python interactive_pdf_splitter.py`
3. 按照提示选择PDF文件和设置参数
4. 确认后开始分割

### 方法二：使用批处理脚本
1. 确保PDF文件在 `big` 目录中
2. 双击运行 `split_pdfs.bat`
3. 等待分割完成

### 方法三：使用命令行工具
1. 打开命令行
2. 使用 `pdf_splitter.py` 手动指定参数

## 输出说明

- 分割后的文件将保存在指定的输出目录中
- 文件命名格式：`原文件名_part1.pdf`, `原文件名_part2.pdf`, ...
- 每个文件包含指定数量的页面（最后一个文件可能页数较少）

## 注意事项

1. **文件权限**: 确保对输入文件有读取权限，对输出目录有写入权限
2. **磁盘空间**: 分割后的文件总大小可能略大于原文件
3. **文件完整性**: 工具会保持PDF的原始质量和格式
4. **中文支持**: 工具完全支持中文文件名和路径

## 故障排除

### 常见问题

1. **ImportError: No module named 'PyPDF2'**
   - 解决方案：运行 `pip install PyPDF2`

2. **权限错误**
   - 解决方案：确保以管理员身份运行，或检查文件权限

3. **文件无法读取**
   - 解决方案：检查PDF文件是否损坏，尝试用其他PDF阅读器打开

4. **中文乱码**
   - 解决方案：确保使用UTF-8编码的命令行环境

## 技术说明

- **Python版本**: 支持Python 3.6+
