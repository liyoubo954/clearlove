# RAGFlow文档重新上传指南

由于已成功将搜索引擎从Elasticsearch切换到Infinity，之前的所有文档数据已丢失。本指南将帮助您重新上传和处理文档到新的Infinity数据库中。

## 📋 准备工作

### 1. 确认服务状态
首先确认RAGFlow服务正常运行：
```bash
# 检查容器状态
docker ps | grep ragflow

# 确认Infinity服务健康
curl -s http://localhost:23820/admin/node/current
```

### 2. 访问RAGFlow界面
- 打开浏览器访问：`http://your-server-ip` 或 `http://localhost`
- 使用管理员账户登录

## 📁 文档上传步骤

### 步骤1：创建知识库
1. 登录RAGFlow管理界面
2. 点击左侧菜单「知识库」
3. 点击「+ 新建知识库」
4. 填写知识库信息：
   - **名称**：为知识库起一个有意义的名称
   - **描述**：简要描述知识库内容
   - **语言**：选择文档主要语言（中文/英文等）
5. 点击「确定」创建

### 步骤2：上传文档
1. 进入刚创建的知识库
2. 点击「上传文档」按钮
3. 选择文档上传方式：
   - **本地上传**：直接上传本地文件
   - **网络链接**：通过URL上传
   - **批量上传**：上传多个文件

#### 支持的文档格式
- **PDF文件**：`.pdf`
- **Word文档**：`.doc`, `.docx`
- **文本文件**：`.txt`, `.md`
- **Excel表格**：`.xls`, `.xlsx`
- **PowerPoint**：`.ppt`, `.pptx`
- **网页文件**：`.html`

### 步骤3：配置文档解析
上传文档后，需要配置解析参数：

1. **选择解析模式**：
   - **智能解析**：自动识别文档结构（推荐）
   - **表格解析**：专门处理表格数据
   - **图像解析**：提取图片中的文字

2. **设置分块参数**：
   - **分块大小**：建议512-1024字符
   - **重叠长度**：建议50-100字符
   - **分块方式**：按段落/按句子/按固定长度

3. **配置向量化**：
   - **嵌入模型**：选择合适的embedding模型
   - **向量维度**：根据模型确定

### 步骤4：开始处理
1. 确认配置无误后，点击「开始解析」
2. 系统将自动进行：
   - 文档内容提取
   - 文本分块处理
   - 向量化计算
   - 存储到Infinity数据库

## 📊 监控处理进度

### 查看处理状态
1. 在知识库页面可以看到文档处理状态：
   - **等待中**：排队等待处理
   - **处理中**：正在解析和向量化
   - **已完成**：处理成功，可以检索
   - **失败**：处理出错，需要重新上传

### 处理时间估算
- **小文件**（<1MB）：1-5分钟
- **中等文件**（1-10MB）：5-15分钟
- **大文件**（>10MB）：15分钟以上

## ⚠️ 常见问题及解决方案

### 问题1：文档上传失败
**可能原因**：
- 文件格式不支持
- 文件大小超限
- 网络连接问题

**解决方案**：
- 检查文件格式是否在支持列表中
- 压缩大文件或分割处理
- 检查网络连接稳定性

### 问题2：处理速度慢
**可能原因**：
- 系统资源不足
- 文档内容复杂
- 并发处理过多

**解决方案**：
```bash
# 增加Infinity内存限制
# 编辑docker-compose-base.yml中的infinity服务
mem_limit: 4g  # 根据实际情况调整

# 重启服务
docker-compose restart infinity
```

### 问题3：检索结果不准确
**可能原因**：
- 分块参数不合适
- 嵌入模型选择不当
- 文档质量问题

**解决方案**：
- 调整分块大小和重叠长度
- 尝试不同的嵌入模型
- 清理和预处理文档内容

## 📈 性能优化建议

### Infinity配置优化
编辑 `docker/infinity_conf.toml`：
```toml
# 增加内存配额
memindex_memory_quota = "4GB"

# 优化缓存设置
result_cache = "1GB"

# 调整并发处理
max_concurrent_query = 16
```
